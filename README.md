# protoScrape
Web scraper with PyQt5 UI.

## Features
- Scrape photos, videos, page structure (CSS/JS), or all of the above
- Configurable crawl depth
- Stop scraping at any time
- All output saved locally with resources relinked

## Requirements
```
pip install requests beautifulsoup4 PyQt5
```

## Usage
```
python main.py
```
